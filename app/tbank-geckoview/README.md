# T‑Bank GeckoView — desktop mode experiment

Отдельный Android-прототип для проверки личного кабинета Т‑Банка в независимом браузерном движке Mozilla GeckoView.

## Что проверяется

GeckoView официально поддерживает два независимых параметра, которых нет у системного Android WebView:

- `USER_AGENT_MODE_DESKTOP`;
- `VIEWPORT_MODE_DESKTOP`.

Приложение также задаёт виртуальный экран 1280×900 и открывает официальный раздел:

```text
https://www.tbank.ru/mybank/operations/
```

## Безопасность и ограничения

- Это отдельное приложение `com.finuchyot.tbank.gecko`; существующая WebView-сессия не переносится.
- Пользователь вручную проходит штатную авторизацию на странице Т‑Банка.
- Основная навигация допускается только по HTTPS на `tbank.ru`, `tinkoff.ru` и их поддоменах.
- Remote debugging, console output и login autofill отключены.
- В коде нет JavaScript-интерфейсов, чтения DOM, cookies, Web Storage или SMS.
- Исходный код ZenMoney не использовался.
- Автоматические клики в этой версии отсутствуют: сначала проверяется ручное скачивание официального CSV.
- Версия 0.2 перехватывает только CSV-ответ с доверенного HTTPS-домена Т‑Банка, ограничивает размер 25 MiB и сохраняет файл во внутренний каталог приложения `files/reports`; общий Android Downloads и дополнительные storage-разрешения не используются.
- Кнопка «Отчёты» показывает список локальных CSV. Нажатие запускает диагностический импортёр версии 0.6: локально определяются UTF‑8/UTF‑8 BOM/Windows‑1251, разделитель `;`/`,`/tab, заголовки, количество корректных и ошибочных строк и диапазон дат.
- Диагностический экран не показывает значения строк: суммы, назначения, продавцов, номера счетов и карт. Операции пока не записываются в базу, исходный CSV не изменяется.
- Сборка предназначена только для ARM64 (`arm64-v8a`).
- GeckoView добавляет собственные технические разрешения `ACCESS_NETWORK_STATE`, `HIGH_SAMPLING_RATE_SENSORS`, `WAKE_LOCK` и `MODIFY_AUDIO_SETTINGS`; приложение само запрашивает только `INTERNET`.
- APK большой (~191 MiB), потому что содержит самостоятельный Firefox/Gecko-движок.

## Испытание

1. Установить APK рядом с WebView-прототипом.
2. Нажать «Операции (ПК)».
3. Заново пройти авторизацию.
4. Проверить, отображается ли общий десктопный список операций.
5. Проверить наличие выбора периода, продуктов и экспорта CSV/XLSX.

Не присылайте скриншоты с балансами, номерами счетов или операциями. Достаточно описать структуру интерфейса.

## Сборка

Требуются JDK 17, Gradle 8.11.1, Android SDK 36 и Android Gradle Plugin 8.9.1.

```bash
cd ~/FinUchyot/app/tbank-geckoview
gradle --no-daemon testDebugUnitTest lintDebug assembleDebug
```
