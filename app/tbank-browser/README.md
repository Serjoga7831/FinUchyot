# T‑Bank Browser Connector — экспериментальный прототип

Экспериментальный Android-клиент для проверки безопасной схемы:

1. пользователь вручную открывает официальный сайт Т‑Банка внутри локального WebView;
2. пользователь сам проходит штатную авторизацию;
3. сессия остаётся в изолированном хранилище приложения;
4. официальный экспорт скачивается через интерфейс банка;
5. загруженный файл можно передать в FinUchyot.

## Ограничения безопасности

- Основная страница WebView разрешена только на HTTPS-доменах `tbank.ru` и `tinkoff.ru`.
- Отладка WebView отключена.
- Cleartext HTTP, доступ к локальным файлам и сторонние cookies отключены.
- Приложение не содержит JavaScript-интерфейсов и не записывает форму входа, OTP, быстрый код или cookies в логи.
- Исходный код ZenMoney не использовался.
- Приватные API Т‑Банка не используются.
- Сессия браузера не гарантированно read-only и должна считаться чувствительным банковским доступом.

## Важное ограничение прототипа

Приложение **не прошло реальную авторизацию**, потому что она требует участия владельца счёта на его телефоне. Кроме того, Т‑Банк может запрещать вход из Android WebView. APK проверяет именно эту гипотезу.

Обычные HTTPS-загрузки поддерживаются через Android DownloadManager. Экспорт в виде JavaScript `blob:` в этой версии не поддерживается.

## Сборка

```bash
source ~/android-tools/env.sh
cd ~/FinUchyot/app/tbank-browser
gradle --no-daemon assembleDebug
```

APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Отключение

1. В приложении Т‑Банка отозвать соответствующую активную сессию.
2. Удалить приложение FinUchyot — Т‑Банк.
3. Данные WebView и загруженные файлы удалятся вместе с приложением.
